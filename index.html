Unravel

Understand any codebase in minutes.

Unravel reads a software project and draws an interactive map of how its parts connect, so a new developer can see the big picture instead of reading thousands of files. It runs entirely in your browser, so your code is never uploaded. It also works as a Claude Code plugin that writes a plain-English BLUEPRINT.md for the project.
